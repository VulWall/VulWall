Severity pill for vulnerability findings — the five-band scale, decoupled from brand orange.

```jsx
<SeverityBadge level="critical" />
<SeverityBadge level="high" />
<SeverityBadge level="medium" />
<SeverityBadge level="low" />
<SeverityBadge level="info" />
```

`level`: `critical` (maroon) · `high` (red) · `medium` (amber) · `low` (gold) · `info` (slate). Each renders a tint background, readable text, and a solid status dot. Pass `label` to override the text.
